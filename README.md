# Texas A&M S&C — Continuing Education Dashboard (public site)

This repo holds the single-file dashboard published at the team's Netlify link.

- `index.html` is the entire site (self-contained).
- Netlify is connected to this repo: any push to `main` auto-deploys.
- A monthly Cowork scan refreshes `index.html` and pushes it here automatically,
  so the live site stays current with no manual steps.

Do not hand-edit `index.html` here; it is regenerated by the monthly scan.
